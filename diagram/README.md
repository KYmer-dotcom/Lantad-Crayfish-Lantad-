# Level 1 Data Flow Diagram (Draw.io)

This directory contains the editable **Draw.io** diagram for the **Level 1 Data Flow Diagram (DFD)** of the **Aquaculture Value Chain Management System with Predictive Analytics**.

---

## Files in this Directory

- **`Level_1_DFD.drawio`**: Standard draw.io file (can be opened with [diagrams.net / app.diagrams.net](https://app.diagrams.net) or the Draw.io Integration extension in VS Code).
- **`Level_1_DFD.xml`**: Standalone XML source format for draw.io.

---

## Diagram Structure

### 1. External Entities (Left Column)
- **Customer**
- **Rider**
- **Owner**

### 2. Core Processes (Center Column - Gane & Sarson DFD Format)
- **1.0**: Browse and select
- **2.0**: Order management
- **3.0**: Payment & Set location
- **4.0**: Delivery dispatch
- **5.0**: Management
- **6.0**: Report and Monitoring
- **7.0**: Predictive Analytics

### 3. Data Stores (Right Column)
- **D1**: Order
- **D2**: Customer
- **D3**: Production
- **D4**: Expense
- **D5**: Payment
- **D6**: Delivery

### 4. Data Flows
Contains all 46 labeled directional orthogonal data flow lines connecting entities, processes, and data stores exactly as specified in the reference architectural diagram.
